<h1>Descripción</h1>
<p>Desarrollo de una plataforma web donde los instructores pueden gestionar y publicar sus cursos, y los alumnos pueden explorar la oferta e inscribirse. Implementación de interfaz con React y lógica de servidor en Java.</p>
